# Good first issues

The tasks that stand on their own are issues on GitHub, where you can say you pick one up, ask about it and link your
pull request to it: [open issues labelled good first issue](https://github.com/factiz-org/factiz/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).
You can do them without the lab's database and without API keys, and each one names where to start and when it is done.
The plan item in brackets is where the task lives in `docs/PLAN.md`.

## Without code

- [#1 Read the site in your language](https://github.com/factiz-org/factiz/issues/1): one of the 15 languages of the
  site, none of which a native speaker has read yet.
- [#2 Check the negation rules for a South or Southeast Asian language](https://github.com/factiz-org/factiz/issues/2)
  (PLAN #25.20).
- [#3 Tell us about a newsroom we are missing](https://github.com/factiz-org/factiz/issues/3).
